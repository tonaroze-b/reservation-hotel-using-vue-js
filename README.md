# 🏨 Hotel Reservation - Vue.js

A hotel reservation web application built with Vue.js, allowing users to check hotel availability and make reservations.

## 🚀 Features

- 📅 Check hotel availability
- 🛎️ Make reservations
- 📱 Responsive design

## 🛠️ Technologies

- Vue.js
- JavaScript
- jQuery
- Bootstrap
- HTML5
- CSS3
